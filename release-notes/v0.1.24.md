# dsh-agent-teams-fish v0.1.24

上游 [NanmiCoder/dsh-agent-teams](https://github.com/NanmiCoder/dsh-agent-teams) `v0.1.22`（commit `9cba4fe`）的**补充版**发布：在 npm `latest` 上提供稳定版本，目标宿主仍为已发布的 DeepSeek Harness `0.2.0-rc.2`。

## 本版新增

- **岗位匹配大扩充**：成员头像的 8 个成员岗位关键词全面补齐 —— 架构/模块/接口/运行时/装配、校验/核验/体检/回归/冒烟、合规/风控/权限、调研/资料/情报、视觉/界面/交互/样式/皮肤/美术/插画/立绘/出图、说明/手册/教程/文案、埋点/统计/报表/指标/连击/计分/得分、部署/发布/上线/流水线/调度/编排。真实角色文字的命中率显著提升（例如「美术管线」命中设计与前端、「交互层」命中设计与前端、「战局层」的判定与计分命中数据与分析）。
- **路径与文件名不再污染判定**：匹配前剥离角色文字里的目录型与文件型 token（例如 `team-site-test/`、`verify.ps1`），修复「实现者被项目目录名里的 `test` 抢成测试岗」「安全评审者被 `verify.ps1` 抢走」这一类误判。
- **中文岗位名与适配提示**：面板头像 tooltip 与点击放大预览显示中文岗位名（如「岗位：工程师 · 点击查看大图」）；未命中岗位时显示「该岗位形象作者正在尽快适配」。zh/en 两个语言块同步补齐，英文环境不再出现中英混排。
- **厂商通用大图兜底**：未命中任何岗位但厂商已知时，改用该厂商通用大图（`member-<vendor>-v2.png`，放大用 `-full-v2.png`）并标注适配中；厂商未知仍回退首字母徽标；取图失败时回退首字母徽标，不出现破图。
- **厂商识别收紧**：9 家厂商正则统一加词边界，新增混元 `hy-` 前缀与 `zhipu` provider 变体，避免 `hy` / `ds` 一类短 token 误命中英文单词。
- **音频预留为独立岗位**：音频类角色文字（音频引擎、程序化音色合成、混音总线…）**故意保持未命中**，等待后续单独增设的音频岗位与配套立绘，不强行并入现有岗位。
- **修复第一轮审查的全部 4 条 finding**：队长放大预览误显示适配提示、`zhipu` 变体未落正则、`ROLE_LABELS` 注释与实际用法不符、「岗位：」前缀硬编码中文未走 locale。

## 安装

> 仓库已改名为 **`Fish-under-sea/dsh-agent-teams-fish`**（与 npm 包名一致）：本版同步更新了 `publish.yml` 的仓库名守卫（旧名会让 tag 触发的发布整场 skipped）、`package.json` 的 `repository` / `bugs` / `homepage`，以及 README / NOTICE 中的链接。旧地址仍可通过 GitHub 重定向访问。

```bash
# 单独安装
dsh plugin --profile <profile> add dsh-agent-teams-fish

# 或安装自建聚合包，会一并带出本插件
dsh plugin --profile <profile> add @fish-under-sea/dsh-fish
```

包名、`cordis.patch.yml` 的行 `name`、客户端包 `lib/client.js` 的注册 `id` 三处必须一致，否则浏览器侧会报 `loaded without registering "<包名>"`。版本号里的上游基线（`v0.1.22`）是**事实说明**，与本版自身版本号无关。

- 确定性测试与静态检查**不构成**真实 provider 或打包后 Electron 的验收；本版的美术与文案效果以 GUI 实际观感为准。
