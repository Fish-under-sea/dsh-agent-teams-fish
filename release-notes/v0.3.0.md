# dsh-agent-teams-fish v0.3.0

上游 [NanmiCoder/dsh-agent-teams](https://github.com/NanmiCoder/dsh-agent-teams) `v0.1.22`（commit `9cba4fe`）的**补充版**发布：在 npm `latest` 上提供稳定版本，目标宿主仍为已发布的 DeepSeek Harness `0.2.0-rc.2`。

## 版本号说明

版本号从 `0.1.x` 收到 **`0.3.0`**：`0.1.25`–`0.1.29` 的迭代此前只发到 npm、没有配套的发布说明与 GitHub tag，本版把它们一并收进来，GitHub 侧的 tag / Release 也从 `v0.1.24` 直接对齐到 `v0.3.0`。**本版没有新增功能代码**，改动面就是下面这份累积清单加上版本号与制品戳。

## 本版新增（自 v0.1.24 起累积）

- **角色词表规范化，修掉整队掉兜底头像**（0.1.27）：`ARTWORK_ROLES` 新增 `audio` / `video` 两个岗位桶（美术未出图时沿 vendor / team-lead 兜底）；客户端 `ROLE_ART` 补上 `author` / `writer` / `作者` / `写手` / `edit` / `readme` → `docs` 等漏词 —— 这是实机出现过的 `plugin-author-a` / `home-author` **整队掉厂商通用大图**的根因；`agent_teams_create` 等三处工具描述**直接公布可选用词表**，让队长按桶选角色而不是自造名词（词表外的 `reviewer` 示例也一并修掉）。
- **回滚客户端面板字典，修桌面端 renderer 启动失败**（0.1.28）：诊断包证据 `renderer.boot.failed / pluginIds=[dsh-agent-teams-fish]` —— 客户端注册 `command` 命名空间字典 + `LocaleNamespaceMap` 增强会让桌面端 renderer 起不来。已回滚客户端唯一差异，指令中文化改由 **Host 侧描述符与结果文案**承担（面板以内置兜底显示中文）；角色词表规范化保持不变。顺手把误提交的 `debug.log` 移出版本控制并加进 `.gitignore`。
- **斜杠命令说明格式统一**（0.1.29）：指令说明改为 `中文标签 · 说明` 格式。
- **README 重排**（0.1.25）：居中标题 + 五枚徽章、章节去掉 emoji 前缀并统一顺序、新增目录与独立「配置」节（`stateDir` / `memberProvider` / `artworkDir`）。

## 安装

```bash
# 单独安装
dsh plugin --profile <profile> add dsh-agent-teams-fish

# 或安装自建聚合包，会一并带出本插件
dsh plugin --profile <profile> add @fish-under-sea/dsh-fish
```

装完**重启 DSH**（宿主插件代码不热重载）。
