# dsh-agent-teams-fish v0.1.23

上游 [NanmiCoder/dsh-agent-teams](https://github.com/NanmiCoder/dsh-agent-teams) `v0.1.22`（commit `9cba4fe`）的**补充版**发布：在 npm `latest` 上提供稳定版本，目标宿主仍为已发布的 DeepSeek Harness `0.2.0-rc.2`。

## 相对上游新增

- **自定义美术目录**：新增 `artworkDir` 配置与对应的资源路由，不改一行动画代码就能整体替换头像与徽标；配置了自定义目录时资源响应改为 `no-store`，换图立刻生效。
- **厂商头像命名空间**：`member-<vendor>-<role>[-full]-v2.png`，覆盖 9 家厂商 × 8 个岗位；缺图时按 `vendor+role → role → vendor → 包内默认` 逐级降级，`-full` 缺失时回落到非 `-full` 同名图。
- **厂商商标徽标**：`brand-<vendor>.svg` 共九枚，用于成员状态角标（圆形裁切 + 描边）。
- **队长与会话头像**：`team-lead-<vendor>[-full]-v2.png`，并提供不区分厂商的 `team-lead-v2.png` 兜底。
- **包名**：以 **`dsh-agent-teams-fish`**（无 scope）发布，上游包名 `@nanmicoder/dsh-agent-teams` 属原作者、本版不沿用。

## 安装

```bash
# 单独安装
dsh plugin --profile <profile> add dsh-agent-teams-fish

# 或安装自建聚合包，会一并带出本插件
dsh plugin --profile <profile> add @fish-under-sea/dsh-fish
```

包名、`cordis.patch.yml` 的行 `name`、客户端包 `lib/client.js` 的注册 `id` 三处必须一致，否则浏览器侧会报 `loaded without registering "<包名>"`。版本号里的上游基线（`v0.1.22`）是**事实说明**，与本版自身版本号无关。

## 校对范围

发布前在本仓库跑过：`npm run typecheck`、`npm run build`、`scripts/verify.mjs`（186 项自检全部通过，含本版修复的两条）、美术路由链单测 16/16、`npm run verify:release` 6/6、`npm run verify:readme`，以及完整的 `npm run verify` 链。

需要留意的一点：整链并发运行时，上游的 `scripts/lifecycle-verify.mjs`（队长接管与驻留回归套件，与本版三处改动无关）偶发**时序性失败** —— 单独运行 `node scripts/lifecycle-verify.mjs` 连续两次均为 `all lifecycle checks passed`。

确定性测试与静态检查**不构成**真实 provider 或打包后 Electron 的验收；本版的美术效果以 GUI 实际观感为准。
