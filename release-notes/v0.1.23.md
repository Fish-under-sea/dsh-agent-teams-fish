# AgentTeams v0.1.23

Stable plugin release on npm `latest`. The recommended host remains DeepSeek Harness `0.2.0-rc.2`; the exact eight-host support matrix is unchanged.

## Changes

- Fix Unicode team cards and legacy event folding so member rosters use the same team identity as persisted state (#203).
- Reject invalid finding line numbers before persistence and normalize recoverable historical values (#188).
- Resolve member models together with their configured provider, and preserve explicit provider selections (#189).
- Record member turn failures that arrive after task settlement as durable captain notes (#205).
- Bind review and verification verdicts to the actual artifact bytes and complete repair lineage; changed files block delivery until covered by a sound verdict (#161).
- Preserve repair contracts, expose stale source warnings, and create repair/reverification follow-ups for failed verification without deadlocking on failed dependencies (#174, #175).
- Escalate findings outside the permitted repair scope with a reason instead of creating impossible repair tasks (#183).
- Preserve captain identity across warm and cold forks, including multihop lineage and member wake-ups (#176).
- Write session source metadata in the current format and ship an explicit, non-destructive historical recovery utility with source backups (#160).
- Add owner-configured member tool policies. Members select a policy ID; the four required coordination tools remain available. This controls tool availability and is not an operating-system sandbox (#59).

## Install

In Plugins → Add plugin, enter `@nanmicoder/dsh-agent-teams@0.1.23`. For CLI profiles:

```sh
dsh plugin --profile web add --save-exact @nanmicoder/dsh-agent-teams@0.1.23
```

Restart the target profile after installation. A global CLI update does not change a desktop application's embedded host.

## Verification scope

The source candidate passed typechecking, build, the full project verification suite, and 121 added regression cases. Local macOS arm64 acceptance used the official Harness `0.2.0-rc.2` Loader, real workspaces, and the existing `deepseek-account / deepseek-flash` login without new API keys. It exercised actual member file writes, failed verification followed by repair and independent rechecking, read-only review, cold fork recovery, and content-drift delivery blocking. Integration acceptance included a captain-driven role/contract correction; the original failed observations are retained.

Publication requires Ubuntu/Windows static checks and the eight-host runtime matrix against one immutable tarball. CI uses deterministic model fixtures with real host implementations; those checks are separate from the local real-provider acceptance. Real account HTTP 429 responses, packaged Electron, and Windows product execution were not covered by that local acceptance.

See [the issue triage and acceptance records](../docs/issue-maintenance-2026-10-10/README.md) for individual evidence and limits. #103's original reproduction already passed on the baseline; no speculative scheduler change is included. Third-party plugin reports and the broader #70/#71 feature requests are outside this release.
